# 规避设计思路

## 目标

在不丢掉核心工程目标的前提下，提出可降低权利重合风险的技术改动方向。

## 原则

- 规避建议必须是技术建议，不要把法律结论伪装成事实
- 只改名称没有意义
- 只改数字但不改技术路径，通常也不够

## 常见规避轴

### 1. 结构轴

- 一个部件拆成两个
- 两个部件并成一个不同模块
- 把特征从活塞路径移到储液路径
- 把环形件改成板、套、筋、腔、槽道

### 2. 连接关系轴

- 外置改内置，内置改外置
- 同轴改偏置
- 直接接触改间隔或弹性支承
- 固定支承改浮动支承

### 3. 流道轴

- 重布流路
- 改变节流和分离的先后顺序
- 改变旁通位置
- 封闭腔改开口或通气路径

### 4. 控制轴

- 更换控制变量
- 改变执行器位置
- 把补偿逻辑从硬件移到软件，或反过来

### 5. 参数轴

仅当权利要求真正依赖参数范围时才使用：

- 厚度
- 孔径
- 刚度
- 预紧力
- 温度或频率窗口

### 6. 材料/工艺轴

- 更换材料体系
- 更换表面处理
- 更换成形工艺
- 更换连接工艺

## 输出模板

每个规避方向至少写清：

- 改什么
- 为什么可能降低重合
- 会带来什么性能风险
- 需要做什么验证

示例：

```text
方向 A：将连续环形导流件改为分段式导流肋
降低重合原因：避开连续环绕结构与封闭腔组合特征
工程代价：可能影响消泡效率和装配公差
建议验证：台架消泡试验、NVH 对比、装配侧向力检查
```
