# 中国专利申请可行性检查表

## 适用时机

当没有发现强阻断权利，或用户追问“这个方案值不值得在中国申请”时使用。

## 1. 新颖性

- 是否有单一近似文献已经披露全部核心特征
- 差异点到底是结构性的、关系性的、功能性的，还是只是换了说法
- 依赖的新特征是否写得足够具体

如果新颖性依赖未写明的参数、图纸或连接细节，要立刻标出来。

## 2. 创造性

- 为什么本领域技术人员不会轻易把最接近文献组合出来
- 方案解决了什么技术矛盾或取舍
- 效果是由机理支撑、数据支撑，还是两者兼有

常见的创造性偏弱信号：

- 只是常规尺寸优化
- 只是选常见材料且无特殊效果
- 只是改阈值，没有新的控制思路

## 3. 工业实用性

- 能否制造、装配并稳定使用
- 工作路径是否物理上自洽
- 技术效果是否依赖不现实的行为

## 4. 充分公开

最终交底书至少应支持：

- 部件清单
- 连接关系
- 工作原理
- 至少 1 个实施例
- 有用的参数范围或实例
- 与结构/逻辑挂钩的技术效果

## 5. 权利要求布局

检查现有材料是否足以支持：

- 产品/装置
- 方法/工艺
- 控制方法
- 系统

只有材料真的支撑时，才建议多种权利要求类型并行。

## 6. 优先补的数据

- 已知最接近的专利号
- 体现部件关系的图纸
- 台架数据
- NVH 或耐久数据
- 参数窗口
- 变型实施例

## 建议用语

- `现阶段具备申请基础，但需要补强差异点和实施例`
- `新颖性初步可行，创造性论证仍偏弱`
- `可考虑同时布局产品权利要求和方法权利要求`
- `公开充分性不足，不建议直接进入正式申请文本`
