# ZF 式专利书写要点

以下要点用于把交底材料写得更接近成熟减振器专利的表达方式。

## 1. 标题命名

标题优先稳，不追求花哨。

- 零部件类：`XX件和减振器`
- 总成类：`XX总成和减振器`
- 系统类：`XX总成、主动减振器和减振器油路系统`
- 方法类：`XX方法、系统和相关设备`

如果同一对象存在多个独立问题，可允许标题接近，但独立权利要求的核心技术特征必须明显不同。

## 2. 背景技术四步法

1. 该对象在整机中的作用
2. 现有常见结构或最接近方案
3. 1-2 个具体工程缺陷
4. 自然引出本案技术问题

不要直接上来写“本领域技术人员都知道……”，也不要只写“现有技术存在不足”这种空话。

## 3. 技术问题写法

优先写成矛盾式或缺口式表达：

`现有方案在 A 场景下存在 B 缺陷，导致 C 后果，因此需要一种能够实现 D 并避免 E 的方案。`

这样更容易带出后续权利要求中的关键技术特征。

## 4. 独立权利要求骨架

### 结构或实用新型

优先采用：

`基础本体 + 新增结构 + 空间位置关系 + 装配/导通/限位关系`

### 装置或系统发明

优先采用：

`系统架构 + 关键功能单元 + 不同工况下的导通/切换/响应关系`

### 方法发明

优先采用：

`触发条件 + 状态检测 + 判断或映射 + 输出或控制动作`

## 5. 从属权利要求展开方向

优先沿以下方向补层次：

- 形状
- 位置
- 连接
- 通路
- 状态
- 工况
- 材料
- 参数范围
- 变型实施例

## 6. 有益效果写法

优先写成：

`结构/逻辑变化 -> 作用机理 -> 工程效果`

常用措辞：

- `通过……`
- `从而……`
- `有助于……`
- `可降低……`
- `可避免……`

没有实测数据时，不把效果写成已被验证的绝对事实。

## 7. 什么时候要拆案

遇到以下情形时，优先考虑拆成多件交底：

- 同一零部件对应多个独立技术问题
- 同一总成存在多条不同技术路径
- 同时存在机械结构创新和控制逻辑创新
- 同时存在平台级总方案和可快速授权的具体结构

原则是按“技术问题”或“技术路径”拆，而不是把所有改进点塞进一件。
