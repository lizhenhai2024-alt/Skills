# 系列化布局判断要点

把一个减振器相关创意从“能不能报”推进到“该怎么布”，至少回答下面五个问题。

## 1. 是单点改进，还是多问题并存

优先检查同一对象是否同时覆盖多个彼此独立的问题，例如：

- 防尘
- 密封
- 导向
- 缓冲
- NVH
- 装配
- 成本
- 寿命

如果每个问题都能对应一套相对独立的关键特征，就优先考虑拆案，而不是把所有问题压进一件申请。

## 2. 是一条技术路径，还是多条技术路径

重点看是否同时存在不同的：

- 流道或阀路
- 气路或油路
- 结构连接路径
- 控制逻辑或切换逻辑
- 制造或装配路径

如果不同路径都能独立闭环解决问题，可以同处总成层级，但分别成案。

## 3. 保护层级落在哪一层

常见层级从低到高依次是：

1. 零部件
2. 总成
3. 系统
4. 方法或算法

布局时不要默认只报最低层。若方案同时包含机械结构和控制逻辑，应判断是否需要同步储备更高层级申请。

## 4. 是否适合双轨

在以下场景优先评估 `发明 + 实用新型`：

- 有明确结构创新，适合实用新型快速落权
- 又存在更宽的系统、通路、逻辑或组合关系，适合发明扩保护
- 用户同时关心速度和防御深度

## 5. 是否值得补外围案

核心产品之外，还可评估：

- 检测设备
- 参数检测方法
- 装配工艺
- 注油、抽真空、密封工艺
- 校准、补偿、验证方法

这类外围案通常不是主案替代品，而是平台型保护补强件。

## 快速输出句式

- `建议以总成为主案，同时预留方法案。`
- `建议按技术问题拆分为 A 案与 B 案，避免独立权利要求过度拥挤。`
- `建议以实用新型先锁定结构，再以发明覆盖更宽的通路和控制关系。`
- `除产品主案外，可补一件检测/工艺外围案。`
