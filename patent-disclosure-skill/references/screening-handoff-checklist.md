# 前置筛查交接清单

在把一个方案视为“可以进入交底书起草”之前，尽量从前置筛查中拿到以下信息：

- 结论
- 最强的 3-10 件命中文献
- 最接近独立权利要求摘要
- 是否存在存续中的阻断权利
- 主要差异点
- 高风险时的规避方向
- 在中国申请的可行性判断
- 建议主申请对象：零部件 / 总成 / 系统 / 方法
- 是否建议拆案
- 是否建议 `发明 + 实用新型`
- 是否存在值得补的检测、工艺或验证外围案

## 如何用到起草里

### 背景技术

用最接近的参考方案，把问题描述写得更尖锐，不要只写泛泛背景。

### 技术方案

围绕已经验证过的差异点展开，避免又写回现有技术路径。

### 权利要求骨架

根据权利要求重合分析，决定哪些要素必须进入独立权利要求骨架，哪些更适合放在从属位置。

### 布局边界

把筛查阶段已经看清的“该合并还是该拆开”一并传给起草阶段，避免交底书又把多个独立技术路径重新揉成一件。

## 如果前置筛查结论是高风险

- 不要把交底书写成“可直接申报”
- 先列出必须调整的结构、路径或控制点
- 如用户仍要继续，只输出调整方向版交底草稿
