# 检索策略与关键词展开

## 目标

既要把近似现有技术尽量搜全，也要把真正值得做权利分析的 3-10 件强命中筛出来。

## 检索顺序

1. 从用户原话出发，先做中英文直搜
2. 展开对象、结构、连接关系、功能、问题的同义词
3. 不只搜零件名，也搜问题描述
4. 按技术家族分支检索：
   - 结构
   - 阀系/流道
   - CDC/控制
   - NVH/消泡
   - 材料/工艺
5. 分类号只作辅助，不替代文本检索

## 优先来源

- CNIPA
- WIPO PATENTSCOPE
- EPO Espacenet
- USPTO Patent Public Search
- J-PlatPat

优先使用官方或权威来源，不要先依赖第三方摘要站。

## 关键词展开维度

### 核心对象

- 减振器 / shock absorber / damper
- 阀系 / valve system
- 电磁阀 / solenoid valve
- 活塞杆 / piston rod
- 活塞组件 / piston assembly
- 储液腔 / reservoir chamber

### 功能词

- 消泡 / anti-foaming / defoaming
- 降噪 / noise reduction / squeak reduction
- 阻尼调节 / damping adjustment
- 流量控制 / flow control
- 温度补偿 / temperature compensation
- 密封 / sealing
- 耐久 / durability

### 连接与结构词

- 并联 / 串联
- 位于之间 / arranged between
- 连通 / communicates with
- 形成流道 / forms a flow path
- 节流孔 / throttle hole
- 导流 / 分流

### 问题词

- 泡沫化
- 高频异响
- 阻尼一致性
- 低温性能
- 高温衰减
- 装配干涉
- 漏油

## 何时停止

满足以下任一条件即可停止扩搜：

- 已有 3-10 件强命中可做权利分析
- 新搜分支反复回到同一批家族
- 剩余分支明显弱于当前结果
