# 纠正处理器

用于处理用户指出的错误、参数修正、事实不符、表述调整等纠正场景。

## 执行门禁（优先执行，不可跳过）

1. 读取当前最新版交底书 MD 文件
2. 逐条确认用户的纠正内容（一条一条过，不跳、不合并）
3. 确认后逐条修正
4. 不覆盖旧稿，输出新文件

## 纠正分类

### A 类：事实性错误（高优先级）
- 参数值写错（如"阀片外径 20mm"应为"25mm"）
- 零件名称/编号写错
- 装配关系描述颠倒
- 物理原理表述错误（如阻尼力与速度的关系方向搞反）

处理：直接修正，标注 `[已修正]`。

### B 类：表述调整
- 术语不准确（如写"减震力"应改为"阻尼力"）
- 句式不清晰
- 技术描述过于抽象需要更具体

处理：替换表述，不改变实质内容。

### C 类：结构/流程调整
- 章节顺序要调整
- 某个实施例移到另一处
- 权利要求顺序变更

处理：调整结构，同步更新所有交叉引用。

## 纠正后动作

1. 另存为 `{案件名}_{YYYYMMDDHHmmss}.md` + `.docx`
2. 追加到 `交底书修订对话记录.md`：
```
[时间戳] 纠正操作
- 修正项:
  1. [原表述] → [修正后] (A/B/C类)
  2. ...
- 排除的纠正请求: [如有，说明原因]
- 输出文件: {文件名}
```
3. 在对话中输出**纠正摘要**（不超过 10 行）：

```
纠正摘要
════════
操作时间: [timestamp]
A类（事实性错误）: N 处
B类（表述调整）: N 处
C类（结构调整）: N 处
受影响的章节: [列表]
输出: {文件名}.md / .docx
════════
```
4. 对新稿执行 Step 8 自检 `disclosure_self_check.md`
