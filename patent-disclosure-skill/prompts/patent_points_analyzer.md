# Step 3–4：候选专利点识别 → 讨论融合 → 选定

基于 Step 2 的三列表，识别可专利化的技术点，讨论后选定最终方案。

## Step 3：候选点挖掘

从素材中提取发明构思，每个候选点用三句话描述：

```
候选点 #N: [名称]
- 解决了什么问题（现有技术的局限，1 句）
- 怎么解决的（核心方案，1 句）
- 为什么有效（技术原理，1 句）
```

### 挖掘维度

从以下视角审视素材：

| 维度 | 减振器领域示例 |
|------|--------------|
| 结构变更 | 新增零件、形状改变、布局调整 |
| 参数优化 | 阀片叠层厚度组合、节流面积比 |
| 工艺改进 | 焊接路径、热处理温度窗口 |
| 控制策略 | CDC 电流-阻尼力映射、自适应算法 |
| 材料/涂层 | 阀片材料、密封圈材料、表面处理 |
| 系统集成 | 传感器+ECU+执行器的协同 |

## Step 4：讨论融合与选定

### 4.1 区别对待

- 独立技术问题 → 可能拆案，不硬塞进一个交底书
- 同一总成的多个改进点 → 可作为多个实施例合并
- 方法+对应的装置 → 可同时保护，考虑发明+实用新型双轨

### 4.2 减振器领域拆案判断

| 场景 | 建议 |
|------|------|
| 结构改进 + 控制方法 → 两个独立发明点 | 拆案 |
| 阀系结构 + 消泡环结构 → 不同技术问题 | 拆案 |
| 同一零件多个结构实施例 → 同一技术问题 | 合并，多实施例 |
| 测试/工艺方法围绕核心产品 → 派生布局 | 拆案但协调申请时间 |

### 4.3 与用户讨论确认

将候选点列表呈现给用户，引导：
1. "哪些点你认为最有价值优先申请？"
2. "是否有已公开或你知道的同类方案？"
3. "哪个点建议拆案？哪个合并？"

### 4.4 选定后输出

```
选定方案:
- 案件名称: {技术主题}
- 保护对象: 零部件 / 总成 / 系统 / 方法
- 建议轨道: 发明 / 发明+实用新型双轨
- 核心技术特征: {1-2 句}
- 与最接近现有技术的区别: {1-2 句}
```
