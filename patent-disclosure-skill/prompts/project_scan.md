# Step 2：项目文档扫描

扫描用户提供的项目文档，提取发明素材。目标是形成"已确认事实 / 待确认 / 缺失项"三列表。

## 扫描优先级

按此顺序读取材料：

1. 筛选报告（如有）
2. 设计说明书 / 技术要求书 / 产品定义文档
3. 图纸（CAD 截图、工程图、3D 模型截图）
4. 实验数据 / 测试报告
5. 已有半成品草稿

## Office 文档处理

扫描前如发现 `.docx` / `.pptx`，先用工具转为 Markdown：

```bash
# 工程描述与表格 → docx_to_md
python3 tools/docx_to_md.py --input {path}.docx --output {dir}/{name}.md

# 技术交底与结构图 → pptx_to_md  
python3 tools/pptx_to_md.py --input {path}.pptx --output {dir}/{name}.md
```

依赖：`pip install -r requirements.txt`（mammoth + python-pptx）。

转换后 **Read** 生成的 `.md` 文件，图片抽取在 `{name}_media/` 目录下，如有结构图、标注图一并 Read。

**无法转换的场景**（如旧版 .ppt、图表内嵌 SmartArt）：告知用户"以下文件建议先导出 PDF 再扫"，不强行畸读。

## 图纸/图片解读

- CAD/3D 截图：关注部件标注、装配关系、运动方向箭头
- 实验曲线：识别横纵坐标物理量、对比组、差异区域
- 拍摄照片：关注结构特征的"肉眼可见差异"

如属 ZF 减振器专利，在读图时额外关注：
- 活塞阀系层级结构（主阀→先导阀→电磁铁→阀芯）
- 油路/气路的进出口与节流关系
- 焊接位置、密封结构、材料界面

## 三列表输出

扫描完成后输出：

| 类别 | 内容 |
|------|------|
| **已确认** | 有明确图纸/文档/实验数据支撑的事实 |
| **待确认** | 有线索来源但细节不足的点 |
| **缺失项** | 交底书必备但当前材料中找不到的信息（用 questionnaire_guide 判断） |

## 减振器领域常见缺失项提示

- 阻尼力曲线：不同电流/不同速度下的特征值
- 阀片叠层顺序和尺寸
- 节流口面积变化与流量关系
- 对比现有方案的具体改进量（如：降噪 N dB、响应时间缩短 X ms）
- 焊接参数或材料牌号（若涉及工艺）
