# Step 8：交底书内部自检

定稿后在交底书正式交付用户前，内部执行自检。**自检结果不写入交底书正文**，仅内部分析和修正用。

## 逻辑闭环检查

### 问题→方案→效果链条

```
[2.背景技术中的问题]
       ↓ 对应
[3.发明要解决的技术问题]  
       ↓ 对应
[4.技术方案] → 每个特征是否都在实施例中有对应？
       ↓ 对应
[5.有益效果] → 每个效果是否都有方案特征支撑？
```

如果一个效果声称"降低了阻尼力波动"但没有在方案中说明具体怎么实现的，标记缺失。

### 方案特征自洽

- 检查技术方案中的每个零件/步骤是否在后续正文中再次出现并详细说明
- 权利要求中的每个特征是否能从实施例中找到依据
- 附图标注的每个标号是否在正文中有说明

## 公式与参数一致性

如交底书正文中出现数值或公式：
- 公式中的每个符号是否有定义
- 同一参数在多处出现时数值是否一致（如阀片外径在 §4.2 = 20mm，§6 中也是 20mm）
- 单位是否统一（N·m / MPa / mm 等）
- 表格中的计算值是否与公式推导一致

## 表述规范性（减振器术语检查清单）

| 检查点 | 不良表述 | 规范表述 |
|--------|---------|---------|
| 力术语 | "减震力" | "阻尼力" |
| 行程 | "上下运动" | "复原行程/压缩行程" |
| 阀 | "电磁阀"（泛指） | "电磁阀/先导阀/比例阀"（精确） |
| 油 | "油压" | "工作液压力" 或 "油液压力" |
| 力单位 | "公斤力" | "N"（牛顿） |
| 速度 | "快/慢" | "活塞速度 m/s" |

## 现有技术对比完整性

- 是否至少引用了 1 篇最接近现有技术
- 区别技术特征是否逐条列出
- 区别特征与用户方案之间的因果联系是否清晰

## 修正优先级

发现问题后按以下顺序修正：
1. 标记 `[待确认]` — 信息不足无法判断
2. 修正事实性错误 — 参数、名称、关系明显写错的
3. 补齐遗漏 — 缺附图、缺解释、缺标注
4. 术语替换 — 统一到规范表述

## 自检完成后

修正草案 → 重新确认命名 → 交付 .md/.docx。

**不**在交底书正文中加入"自检报告"或"自检清单"章节。
