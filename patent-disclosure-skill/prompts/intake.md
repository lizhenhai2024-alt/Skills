# Step 1：边界澄清与输入确认

执行此步骤时，与用户确认以下信息。已明确的跳过，缺失的追问补齐。

## 必确认项

- [ ] **技术主题**：发明涉及的具体部件/系统/方法是什么？（如：电控减振器的消泡环、焊接阀片疲劳寿命、CDC 先导阀结构）
- [ ] **申请人/权利归属**：以什么名义申请？（公司/个人/联合）
- [ ] **保护层级**：零部件 / 总成 / 系统 / 方法 / 组合？
- [ ] **交付要求**：仅 Markdown / Markdown + Word / 含 Mermaid 图示 / 含查新报告？
- [ ] **输入材料路径**：设计文档、图纸、实验数据、CAD 截图、已有专利 PDF 的本地路径
- [ ] **是否已有筛选报告**：如有，先读取作为上游输入

## 减振器领域快速边界判断

| 发明对象 | 建议保护层级 | 建议检索重点 |
|---------|------------|------------|
| 消泡环、导圆角、阀片 | 零部件 | 结构类 CPC: F16F9/32~9/34 |
| CDC 电磁阀总成 | 总成 | 阀系 CPC: F16F9/34 + F16K31/06 |
| 控制策略、阻尼力算法 | 方法 | 方法类 CPC: F16F9/46~9/50 |
| 焊接工艺、材料配方 | 工艺/材料 | 工艺类 CPC: B23K + C22C |

## 输入材料检查

- 如果用户给了项目路径，先用 `ls` 了解文件结构
- 标记需要转换的 Office 文件（`.docx`、`.pptx`）
- 标记是否有 ZF 参考专利（`ZF专利/` 目录）

## 完成后

确认以上信息后，进入 Step 2 → `Read prompts/project_scan.md`。
