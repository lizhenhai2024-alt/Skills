# Step 6：摘要预览

交底书全文前，先生成一份精简预览供用户快速确认方向。用户可以选择跳过此步骤，直接进 Step 7。

## 预览内容

```
═══════════════════════════════════
案件名称: {title}
保护层级: 零部件 / 总成 / 系统 / 方法
═══════════════════════════════════

【要解决的问题】
{一句话}

【技术方案（不超过 5 行）】
{核心结构/步骤}

【与现有技术的区别】
1. {区别点 1}
2. {区别点 2}
3. {区别点 3}

【预期效果】
{不超过 3 条}

【推荐专利策略】
- 发明 / 发明+实用新型双轨
- 是否建议拆案: 是 / 否
- 预计权利要求数: X 项

═══════════════════════════════════
```

## 用户确认要点

呈现预览后询问：
1. "方向对吗？有没有理解偏差？"
2. "技术方案的描述准确吗？"
3. "有没有漏掉的关键点？"

用户确认后进入 Step 7 → `Read prompts/disclosure_builder.md` + `prompts/template_reference.md`。

如果用户说"直接写"或"不需要预览"，跳过此步直接进 Step 7。
