# PIMS 知识管理助手

本 skill 包含完整的 PIMS v3.1 知识管理体系。根据用户意图进入以下模式之一。详细规则见 `references/` 目录下的参考文件。

## 四种工作模式

| 用户意图 | 模式 | 详细参考 |
|:--|:--|:--|
| 整理/归档文件 | **归档模式** | `references/archive-rules.md` |
| 建双链/链接知识 | **建链模式** | `references/link-building.md` |
| 查编码/系统结构 | **查询模式** | `references/system-overview.md` |
| 写笔记/日常维护 | **SOP模式** | `references/system-overview.md` |

## 核心原则

- **预览优先**：执行前先列出操作计划，等用户确认后再执行
- **安全第一**：不删除文件，只移动/复制/追加；同名加 `_conflict_YYYYMMDD`
- **全程日志**：每次操作按 G4 格式输出结构化日志
- **先粗后精**：迭代优化，最小摩擦

## PIMS 根目录识别

在执行任何操作前，先确定 PIMS 根目录。按以下优先级检测：

1. **用户明确指定** — 如果用户说"PIMS 在 D 盘"或"整理 H:\PIMS"，直接使用
2. **当前工作目录检测** — 检查当前目录是否包含 `00_Index`、`01_Work`、`04_Knowledge_Base`
3. **自动扫描** — 扫描常见位置（`F:\PIMS`、`E:\PIMS`、`D:\PIMS`、`SSD:\`），找第一个含以上目录结构的路径
4. **询问用户** — 如果都找不到，列出候选盘符让用户选择

确定后输出：`PIMS_ROOT = [路径]`，后续所有归档目标路径都基于此根目录拼接。

执行中的特殊路径处理：
- 规则一至六中的 `SSD:\01_Work\...` 等路径 → 替换为 `{PIMS_ROOT}\01_Work\...`
- 规则二中的 `SSD:\06_Media_Active\...` → 替换为 `{PIMS_ROOT}\06_Media_Active\...`
- 规则三中的 `C:\Users\*\Downloads` → 保持系统路径不变

## 归档模式

**需要完整规则时读取 `references/archive-rules.md`**。执行流程：

1. 判断文件年龄（G7）：<7天跳过，7-30天归档，>30天标注陈旧，>180天单独列出
2. 全局预处理：检查冲突 → 规范化命名 → 跳过系统文件（G1-G3）
3. 按文件类型/来源匹配规则一至六，预览后执行

### 规则速查

| 规则 | 处理对象 | 目标编码 |
|:--|:--|:--:|
| 一 | 工程文件（图纸/计算/报告/PPT） | 0101_Projects |
| 二 | 照片和视频 | 0601_Photos |
| 三 | 下载文件夹清理 | 99→各目标 |
| 五 | 无版本号重复文件（5层识别） | _Superseded |
| 六 | 客户标准PDF（5层识别） | 0102_Standards |

### 项目号识别

```
BM****/BMW**** → BMW\    GY****/Geely**** → Geely\
TY****/Toyota**** → Toyota\    HQ****/Hongqi**** → Hongqi\
BYD**** → BYD\
```

### 客户标准识别

5层：路径关键词 → 文件名关键词 → 标准号格式 → PDF正文 → ZIP解压
标准名：`[客户]_[类型]_[标准号]_[版本]_[日期].pdf`

## 建链模式

**完整流程见 `references/link-building.md`**。按 Step 0→6 执行：

| Step | 内容 |
|:--:|:--|
| 0 | 为PDF生成同名.md代理笔记 |

| 5 | 写入[[双链]] |
| 6 | 输出执行日志 |

- `只对 0410_CDC 执行链接分析`
- `只更新 MOC 文件`
- `只生成 PDF 代理笔记，扫描 Customer_SOR`

## SOP模式

**完整清单和模板见 `references/system-overview.md`**。按频率执行：

| 频率 | 内容 |
|:--|:--|
| 每日5分 | 命名规范→inbox.md→桌面清空 |
| 每周30分 | 清空inbox→清理Temp→一篇笔记→检查备份 |
| 每月1小时 | SSD→HDD同步→超30天归档→C盘检查→git commit |
| 每季2小时 | 备份演练→旧媒体归档→系统镜像→结构审视 |
| 每年半天 | 全盘整理→清理超5年归档→四问复盘→磁盘健康 |

[错误] 文件 | 错误信息
汇总：移动N个，跳过N个，冲突N个，需人工确认N个，错误N个
