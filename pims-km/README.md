# PIMS KM

PIMS (Personal Information Management System) v3.1 知识管理助手，用于文件归档整理、知识库双链构建、工程知识蒸馏（DR/FC/DL笔记）、日常SOP维护。

## 核心能力

- 文件归档（PIMS编码规则 + 目录体系）
- 知识库双链构建（Obsidian [[双链]]）
- 工程知识蒸馏（DR设计规则 / FC失效案例 / DL决策日志）
- MOC索引更新
- SOP日常维护
- inbox清理

## 触发场景

资料整理、归档文件、知识库整理、建双链、文件分类、写DR/FC/DL笔记、日常SOP、inbox清理、更新MOC。
