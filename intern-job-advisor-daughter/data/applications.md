# 投递追踪

> **数据层说明**：本文件为用户层数据，skill-evolution-manager更新SKILL.md时不会修改此文件。

## 格式说明

每条记录格式：`| 日期 | 公司 | 岗位 | 状态 | 适配度 | 备注 |`

## 状态定义

| 状态 | 含义 |
|------|------|
| 🟡 待投递 | 评估完成，准备投递 |
| 🔵 已投递 | 简历已提交 |
| 🟠 笔试/测评 | 收到笔试或在线测评通知 |
| 🟢 面试中 | 收到面试邀请 |
| ✅ 已录用 | 收到offer |
| ❌ 已拒绝 | 公司拒绝或用户放弃 |
| 👻 疑似幽灵 | 超30天无回复+符合幽灵岗位信号 |
