## 核心分析框架（任何分析必须按此路径展开）

### Step 1：流量路径（Flow Path）
- 明确流体路径：上腔 → 阀系 → 下腔
- 判断是否经过：活塞阀 / 底阀 / 电磁阀 / 第三缸

### Step 2：PQ 特性（Pressure-Flow）
- 识别各节流点压降分布
- 确定主控节流位置

### Step 3：FV 曲线（Force-Velocity）
- 由压差 × 面积推导
- 分段分析：低速段 / 中速段 / 高速段特性

### Step 4：控制逻辑链（Current → Force）
```
I（电流）→ 电磁力 → 阀开度 → 流量 → 阻尼力
```

## 关键问题识别与处理

### 问题一：低电流死区（0.3 ~ 0.6 A）

**分析方向（逐项排查）：**
- 电磁力是否不足？
- 先导口是否过大（>φ2.0 mm → 易死区）？
- 液压力是否过高（超过电磁力极限）？
- 弹簧力是否过大？

**判定规则：**
- 先导孔 > φ2.0 mm → 高概率死区
- 控制面积过大 → 分辨率差
- 阀未开启 → FV 曲线无变化

**解决方向：**
- 减小先导孔至 φ1.0 ~ 1.5 mm
- 引入环形缝隙（提高低电流连续可调性）
- 增加压力放大比

---

### 问题二：高电流饱和（> 1.1 A）

**分析方向：**
- 流道是否已全开？
- 主阀是否限制流量？
- 系统是否存在流量瓶颈？

**判定规则：**
- 增大电流但流量不变 → 饱和
- 压降不变 → 流道已全开

**解决方向：**
- 增大主流道面积
- 优化回流路径
- 减少串联节流级数

---

### 问题三：NVH / 噪音 / 气蚀

**流速判断标准：**

| 流速范围 | 评级 |
|---|---|
| < 1.5 m/s | 优秀 |
| 1.5 ~ 2.0 m/s | 可接受 |
| 2.0 ~ 3.0 m/s | 边界，需关注 |
| > 3.0 m/s | 噪音风险高 |

**雷诺数（Re）判断：**
- Re < 2000 → 层流（稳定）
- Re 2000 ~ 4000 → 过渡流
- Re > 4000 → 湍流（噪音↑）

**典型噪音原因：**
- 小孔高速流动 → 尖啸
- 突扩流道 → 涡流
- 多级串联节流 → 流动不稳定

## 阀系设计规则

### 先导控制口尺寸

| 孔径 | 功能区间 |
|---|---|
| φ1.0 ~ 1.5 mm | 控制区（推荐） |
| φ2.0 mm | 边界值 |
| > φ2.3 mm | 接近通流，控制能力下降 |

### 环形缝隙设计

- **优势：** 连续可调，改善低电流分辨率
- **风险：** 加工难度高，同轴度敏感

### 微锥面（5° ~ 15°）

- **优势：** 渐开特性，控制平滑
- **风险：** 密封难，对加工偏差敏感

## 三缸结构检查清单

必须逐项核查：
- [ ] 第三缸容积与活塞排量匹配
- [ ] 油气分离能力是否足够
- [ ] 回油路径阻力是否在允许范围
- [ ] 气体混入风险评估

**常见问题：**
- 压缩初段出现"空行程"（气体未充分分离）
- 回弹侧油量不足（容积设计偏小）
- 泡沫化（高温或高速工况）

## DFMEA 失效模式清单（CDC 专用）

输出 DFMEA 时必须覆盖以下失效模式：

| 失效模式 | 典型影响 |
|---|---|
| 电磁阀卡滞 | 阻尼不可控，固定在软/硬模式 |
| 低电流死区 | 小振幅路面无响应，舒适性差 |
| 高电流饱和 | 硬模式阻尼不足，操稳性差 |
| 阀片疲劳 | 阻尼漂移，一致性失效 |
| 流量漂移 | 不同温度/批次FV曲线偏差 |
| 噪音/NVH | 异响，客户投诉 |
| 泡沫化 | 阻尼突降，车辆失控感 |
| 密封泄漏 | 油液损耗，阻尼失效 |
