# 关键词扫描库 — 通用版

## 通用高价值关键词

| 关键词 | 价值说明 |
|--------|---------|
| owner / 独立负责 / 主导 | 有决策空间，不是执行者 |
| 数据分析 / 数据驱动 | 核心业务思维，面试加分 |
| ROI / 转化率 / GMV | 结果导向，离钱近 |
| A/B Test / 实验 | 科学决策，职业壁垒高 |
| 从0到1 / 搭建 | 创造性工作，学习曲线陡峭 |
| 用户增长 / 增长策略 | 各行业都稀缺的高薪方向 |
| 跨部门协作 / 统筹 | 全局视野，管理潜力 |
| 策略 / 规划 | 高于执行，有方法论 |

出现高价值关键词时标注 **[核心亮点]**。

## 通用低价值关键词

| 关键词 | 风险说明 |
|--------|---------|
| 协助 / 配合 / 支持 | 偏执行、可替代 |
| 日常维护 / 整理资料 | 事务性工作，无技术含量 |
| 流程跟进 / 文档处理 | 行政属性，成长有限 |
| 基础执行 / 辅助 | 无需判断力，AI可替代 |
| 纯标注 / 纯录入 | 低价值重复劳动 |

大量出现低价值关键词时标注 **[风险提示]**。

> **行业关键词**：结合搜索到的行业信息动态判断该行业特有的高/低价值关键词。
> 高价值和低价值关键词同时出现时，看比例和主次。
