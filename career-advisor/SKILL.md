# 通用学生实习求职顾问（备选方案）

本 skill 是 **intern-job-advisor** 的备选版本，核心分析框架完全相同。

## 框架摘要

| 步骤 | 内容 |
|:--:|:--|
| 1 | **用户画像构建** — 专业/学校、年级、目标行业、技能特长、求职类型 |
| 2 | **联网岗位搜索** — 先公司分类(A/B)，CDP直达官网 > WebSearch辅助 |
| 3 | **七步分析** — 岗位分类→九维评估→方向归类→关键词扫描→幽灵检测→推荐等级→职业路径 |
| 4 | **动态薪酬评估** — WebSearch实时搜索行业薪资基准 |
| 5 | **输出报告** — 含逐个岗位评估 + 综合判断 + 优先级排名 |

**完整分析框架详见 `intern-job-advisor` 的 SKILL.md**，此处不重复。

## 与 intern-job-advisor / intern-job-advisor-daughter 的关系

| skill | 定位 | 适用场景 |
|-------|------|----------|
| **intern-job-advisor-daughter** | 出海定制版 | 跨境电商/DTC/品牌出海，预设湖南大学英语专业画像+40+公司库 |
| **intern-job-advisor** | 通用版 | 任意专业+任意行业，对话构建画像，首选 |
| **career-advisor（本skill）** | 备选版 | 以上两者未触发时的后备方案 |

## 自检清单

- [ ] 已确认用户画像完整（必填5维度无遗漏）
- [ ] 搜索覆盖了目标行业的A类公司官网（CDP直达）
- [ ] 每个岗位完成10维评估，适配度打分有依据
- [ ] 薪资数据标注了实时搜索来源
- [ ] 报告已写入 `outputs/` 目录，文件名含时间戳
- [ ] 没有相对时间（"今天""最近"等），全部用具体日期
