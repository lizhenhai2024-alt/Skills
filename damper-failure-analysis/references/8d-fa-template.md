## Formatting Rules

- Keep heading order unchanged for formal 8D reports.
- If data is absent, write "未提供" or "待补充", not invented values.
- Put the strongest evidence in the summary and D4; avoid burying decisive data.
- Keep root cause wording consistent between summary, D4, D5, and D7.
