# Damper Failure Analysis

减振器失效分析专家系统。覆盖被动减振器、CDC电控减振器、电磁阀控制系统、密封系统、结构件全类型。

## 核心能力

- 八步失效分析流程（现象→证据→机理→参数→根因→改进→DFMEA/DVP→质量门）
- 证据分级体系（已确认/高置信假设/待验证/不成立）
- 完整失效模式库（阻尼/NVH/泡沫气蚀/密封/结构/CDC）
- 8D报告（含Is/Is Not分析）
- DFMEA/DVP自动联动
- No-go规则与质量门自检

## 触发场景

减振器异常、漏油、异响、阻尼漂移、泡沫化、密封失效、结构断裂、CDC控制故障、8D报告、DFMEA/DVP更新。
