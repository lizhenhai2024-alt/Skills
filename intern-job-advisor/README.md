# Intern Job Advisor

通用大厂实习求职顾问 — 支持任意专业、任意行业方向的实习与校招岗位搜索、筛选与深度评估。

## 核心能力

- 用户画像构建 + 六步分析法
- CDP浏览器深度搜索
- 动态薪酬评估
- 通用关键词扫描
- offer对比与投递策略

## 触发场景

实习岗位筛选、岗位分析、求职建议、帮看JD、简历匹配、校招准备、offer对比、薪资评估。

**与 intern-job-advisor-daughter 的关系：** 本skill为通用版，适用任意行业方向。跨境电商/DTC/品牌出海方向且用户画像为英语专业，优先使用 intern-job-advisor-daughter。
