| 关键词 | 价值说明 | 级别 |
|--------|---------|------|
| 用户增长 | 英语专业做增长有语言壁垒优势，竞争更小 | 核心 |
| ROI / ROAS | 投放和运营的核心能力，最值钱的数据思维 | 核心 |
| 转化率 | 核心业务指标，经验可迁移 | 核心 |
| A/B Test | 增长黑客基本功 | 核心 |
| CRM | 用户生命周期管理，高阶运营必备 | 核心 |
| DTC | 直接触达消费者，行业最热方向 | 核心 |
| 独立站 / Shopify | 品牌出海主阵地 | 核心 |
| Meta广告 / Facebook Ads | 海外投放核心渠道 | 高 |
| TikTok Shop | 新兴渠道，红利期 | 高 |
| Amazon | 跨境电商基本盘 | 高 |
| 海外用户 | 英语专业天然优势区 | 高 |
| 品牌出海 | 完全契合用户目标方向 | 高 |
| 数据分析 | 虽非技术岗但需要基本数据sense，面试加分项 | 加分 |
| GTM (Go-To-Market) | 消费电子出海核心岗位，英语是壁垒 | 核心 |
| 海外KOL / Influencer | 海外红人营销，英语沟通+执行双重能力 | 核心 |
| KOC | 海外素人营销，增长新方向 | 高 |

> 出现高价值关键词时提醒：**该岗位属于核心业务成长方向。**

## 低价值关键词

| 关键词 | 风险说明 |
|--------|---------|
| 协助 | 偏执行、可替代 |
| 日常支持 | 事务性工作，无技术含量 |
| 整理资料 | 无技术含量 |
| 流程跟进 | 行政属性，成长有限 |
| 文档处理 | 成长有限 |
| 行政事务 | 纯行政 |
| 基础执行 | 无需判断力，AI可替代 |
| 纯翻译 | AI时代风险大，除非同声传译级别 |
| 跟单 | 替代性强、加班严重、成长慢 |

> 大量出现低价值关键词时提醒：**该岗位可能成长有限，偏支持型。**
> 如果岗位同时出现高价值和低价值关键词，看比例和主次。高价值为主则仍推荐，低价值为主则降级。
